# 心晴 · 情绪日记与自我关怀

完整、无依赖的中文静态网页，适配电脑和手机。代码基于 HTML、CSS、JavaScript；无构建步骤，无密钥，无付费模型依赖。

## 功能
- 情绪、强度、时间、多选触发因素及文字日记，本机 localStorage 保存。
- 历史筛选、单条删除确认、JSON 导出和导入去重。
- 最近 7 / 30 / 90 天的每日心情均值、标签频次及低心情共现分析。
- 根据最近记录匹配日常关怀建议、60 秒呼吸引导、浏览器合成和弦/雨声音景、5 分钟轻活动计时。

## 本地打开
直接打开 public/index.html，或在此目录运行 `python3 -m http.server 8080 --directory public`，浏览器打开 http://localhost:8080 。推荐 HTTP 运行以获得稳定的浏览器存储行为。

## 长期公网部署
推荐最简单的静态部署：在 Netlify 的手动部署界面上传 public 文件夹（确保 index.html 位于上传目录顶层）。无构建命令。
GitHub Pages：新建仓库，把 public 目录里的 index.html、style.css、app.js 上传到仓库根目录；Settings → Pages → Deploy from a branch → main / root。不要将整个源码 ZIP 直接作为网页上传。
任何支持静态文件的服务器均可部署 public 内容，不依赖 ChatGPT 服务。使用 HTTPS。网站的长期可用性由你的托管账号及服务商政策决定。

## 隐私与边界
数据只保存在访问者当前浏览器、当前网站域名下，不上传服务器，也不会因发布而公开日记。不同设备、浏览器、域名间不自动同步。隐私模式或清理浏览器数据可能造成记录丢失，请定期导出备份。导出文件含原文，不要上传到公开源码仓库。更换部署域名后可通过导入备份迁移。
本版分析和推荐由透明的本地统计/规则完成，并未接入大语言模型，不做语义诊断或临床判断。情绪分值为低落1、有点烦2、平静3、还不错4、开心5；强度独立记录，不当作正负分。每日均值仅包含有记录的日期，趋势线按记录日期等距展示。标签共现不代表因果。
音景为实时合成声音，不含第三方音乐文件或授权依赖。播放 10 分钟、切换功能页或关闭网页时停止。网页计时器在后台可能被浏览器节流，建议前台使用。
日常关怀内容不能替代专业心理支持。
